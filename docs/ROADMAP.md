# Product roadmap

Retenqo focuses on authorized personal memory and commitment follow-through. See [evaluation guide](EVALUATION_GUIDE.md) and [implementation status](IMPLEMENTATION_STATUS.md) for the current implementation.

| Priority | Direction |
| --- | --- |
| Release reliability | Extend v0.1.4 signed-upgrade verification from API 36 to API 33 and additional devices |
| Privacy and capture | Encrypted durable queue, race-safe deletion and consent revocation |
| Recall | Full-history indexed retrieval and screen-evidence handling |
| Workflow verification | Reminders, backup restore, media and voice on supported devices |
| AI quality | Evaluate extraction, retrieval, grounding and completion suggestions |
| Efficiency | Measure resource use and improve bounded native processing |

These are engineering priorities, not shipped feature claims. Earlier issue references are available in repository history. See [research index](RESEARCH_INDEX.md). Unrestricted phone automation and cloud personal-data processing remain outside the product scope.
